# Система бронирования аудиторий кафедры

## О проекте
Учебный проект по системному анализу.

## Проблема
Отсутствие единого способа просмотра занятости аудиторий
и бронирования помещений для дополнительных занятий,
консультаций или в случае переносов.

## Цель
Разработать модель системы, которая позволит преподавателям
находить подходящие аудитории и управлять бронированиями.

- Заинтересованные стороны и пользователи
- Функциональные требования
- Диаграммы
- Модель данных
